# Vis Aware

Vis Aware 是一款为 NVDA 提供 OCR、AI 图像描述、自动识别和 AI 辅助操作计算机的插件。

大多数引擎需要联网并提供相应服务的凭据，同时我们也内置了完全离线的 RapidOCR 引擎，您还可以借助 Ollama 使用本地自托管服务，例如 Google Gemma 开源大语言模型。

## 快速上手

1. 打开 `NVDA 菜单 > 选项 > Vis Aware 设置...`。在**常规**面板中可输入 [NVDA 中文站账户](https://nvdacn.com/admin/login.php)，用于使用相关的免费社区服务，目前包括 Vivo 提供的图像描述、OCR 和通用大语言模型能力。
    - 如果您拥有其他模型（例如 Kimi、DeepSeek、Gemini 等）提供商的 API 授权，可以根据需要在相应的 **OCR**、**图像描述**或 **AI Agent** 面板中配置。
    - 配置完成后点击“确认”保存相关设置。
2. 按 `NVDA+alt+1` 选择模式：**OCR**、**图像描述**或 **AI Agent**。
3. 按 `NVDA+alt+2` 选择相应模式下支持的引擎，这里应当选择已经在步骤（1）中配置好的引擎，如果登录了 NVDA 中文站账户，可选择 Vivo 的引擎。
4. 按 `NVDA+alt+3` 选择识别来源：**导航对象**、**剪贴板中的图像或图像文件**。
5. 按 `NVDA+alt+space`，按照上述选择的能力类型开始识别：
    - 按一次默认用 NVDA 的识别结果文档呈现，对于 OCR 结果，支持用 `Enter` 或 `Space` 点击文字对应的坐标位置，适用于那些不兼容屏幕阅读器的自绘窗口。
    - 连按两次的行为取决于“常规设置”中的“在浏览模式下显示文本结果”是否选中：若选中该选项，则在 NVDA 的浏览模式对话框中呈现，适用于数学公式、表格或需要 Markdown 渲染的结构化内容；若不选中，NVDA 则只会朗读识别结果，并不显示任何对话框。
    - 如果在步骤（2）中选择了 AI Agent 可以输入指令，让 AI 辅助操作计算机，适用于那些不兼容屏幕阅读器的自绘窗口或多步骤复杂任务。
6. 识别过程中，可以随时按 `NVDA+alt+space` 停止当前任务或开始新的识别任务。

## 模式和识别来源

Vis Aware 提供三种模式：

* **OCR**：从图像中提取文字。
* **图像描述**：描述图像内容。支持追问的引擎可以回答与上一次描述有关的问题。
* **AI Agent**：分析屏幕并根据任务执行计算机操作。

OCR 和图像描述可使用以下识别来源：

* 导航对象
* 整个屏幕
* 前台窗口
* 剪贴板中的图像或图像文件

AI Agent 模式直接截取全屏幕，不使用已选择的识别来源。

## 设置

本插件的所有设置位于 `NVDA 菜单 > 选项 > Vis Aware 设置...`。

设置对话框包含以下面板：

* **常规**：结果显示、复制到剪贴板、自动朗读、调试日志、循环切换时包含的识别来源、Vis Aware 模式和 NVDACN 账户。
* **自动识别**：自动识别类型、引擎、提示词、模型、获取模型和网页图像截图首选项。
* **OCR**、**图像描述**和 **AI Agent**：当前引擎、引擎启用状态和各引擎提供的设置。

对于您不使用的引擎，可以将其禁用。日常使用和切换引擎时会跳过已禁用的引擎。每种模式至少需要保留一个已启用的引擎。

## 按键与手势

以下命令具有默认手势：

| 命令 | 默认手势 |
| --- | --- |
| 循环切换识别模式 | `NVDA+alt+1` |
| 循环切换当前模式的引擎 | `NVDA+alt+2` |
| 循环切换识别来源 | `NVDA+alt+3` |
| 按当前设置执行识别 | `NVDA+alt+space` |
| 对上一次图像描述进行追问 | `NVDA+alt+q` |

以下命令没有默认手势，您需要在 NVDA 的“按键与手势”对话框中自行分配所需的手势：

* 描述当前导航对象的内容
* 描述剪贴板中的图像
* 使用 OCR 识别当前导航对象的内容
* 使用 OCR 识别剪贴板图像中的文字
* 显示上一次识别结果
* 取消当前识别
* 循环切换自动识别模式：关闭、图像描述和 OCR


## 识别结果

识别结果可以用 NVDA 的识别结果文档显示或直接读出，也可以按设置在浏览模式下显示。浏览模式会呈现所支持的 Markdown 和数学公式。还可以将结果复制到剪贴板。

如果 OCR 的结果包含坐标，在识别结果文档中的文字上按 `enter` 或 `space`，会模拟鼠标点击识别区域在屏幕上的对应位置。

当前 NVDA 会话仅保留上一次识别结果。对于支持追问的图像描述引擎，追问命令会打开多轮对话窗口。在该窗口中，按 `control+enter` 发送问题，按 `escape` 取消请求或关闭窗口。使用**查看格式化内容**可在浏览模式下查看对话内容，适用于渲染数学公式或 Markdown 内容的场景。


## AI Agent

AI Agent 会先询问要完成的任务，从前台窗口开始，并可跨窗口操作。AI Agent 可以单击、输入文字、按键、滚动、拖放、导航和等待，并在需要信息时询问用户。每项操作执行前不会逐一确认，请留意其操作，并在需要时将其停止。

AI Agent 每一步都会向所选服务发送全屏截图，其中可能包含其他窗口的内容。请避免在屏幕上显示敏感信息时运行 AI Agent。

## 自动识别

当系统焦点、浏览模式光标或导航对象移到受支持的图形类控件时，自动识别就会在后台启动。结果会自动朗读并保存为上一次识别结果；所用引擎支持时可以继续追问。

自动识别默认关闭。在**自动识别**面板中，可以选择 OCR 或图像描述，再选择当前引擎或一个已启用的特定引擎。提示词和模型仅覆盖该引擎用于自动识别时的设置。提示词留空会使用 Vis Aware 的简洁默认提示词（控制在 20 到 30 字内且不使用 Markdown）；选择**使用引擎设置中选择的模型**会沿用其常规模型。引擎支持时，可以使用**获取模型**加载可用模型名称。

自动识别的引擎列表仅显示支持此功能的引擎。选择“当前引擎”时，如果当前引擎不支持自动识别，自动识别会暂停，切换到支持的引擎后恢复。

对于网页图形，Vis Aware 通常使用图片的 URL；没有可用 URL 时改用对象截图。启用**优先截取网页图像**后，会先识别屏幕上显示的内容，无法截图时再使用 URL。

## 支持的识别引擎

### Be My AI

Be My AI 可以描述图像，并回答关于同一图像的追问。使用时，请打开图像描述设置，选择**登录 Be My Eyes...**，然后输入 Be My Eyes 账户的电子邮箱和密码。Vis Aware 不会保存你的密码。

该引擎支持手动描述和追问，不支持自动识别、自定义提示词和流式输出。如果发送追问后将其取消，请重新识别图像再提出其他问题，否则迟到的回复可能会被当作后续问题的答案。

图像和问题会发送给 Be My Eyes。服务是否可用、账户限制和可用功能由 Be My Eyes 决定，并可能发生变化。对于账户限制、服务变更、数据丢失或使用该服务造成的其他后果，Vis Aware 不承担责任。请遵守 Be My Eyes 的适用条款，并在了解风险后再发送敏感信息。

### 白描 OCR / 公式识别

使用[白描 OCR](https://baimiaoapp.com) 或白描公式识别时，请在 OCR 引擎设置中选择**登录白描...**，然后输入白描账户的电子邮箱或手机号及密码。两个引擎共用同一登录状态。

Vis Aware 会保存用于识别此设备的固定标识，以及设置按钮显示的昵称或脱敏登录账户和会员等级。这些信息使用 Windows DPAPI 加密保护；密码不会保存。公式识别结果会同时提供文字和公式；在可浏览结果中，公式会以便于屏幕阅读器阅读的方式呈现。

两个引擎都使用[白描 Web 版](https://web.baimiaoapp.com/)。设备数限制、额度和可用功能由白描决定，并可能因账户而异。在 Vis Aware 中退出登录会清除本机保存的登录信息，但不保证同时将设备从白描账户中退出；如不再使用某设备，请在手机版白描中将其退出。

此集成使用白描的非公开 Web 接口。该接口可能在不另行通知的情况下变更或停止服务。使用风险由使用者自行承担；对于账户限制、服务变更、数据丢失或其他因使用该接口产生的后果，Vis Aware 不承担责任。请遵守白描适用的相关条款。

### Apple Vision Server

Apple Vision Server 是一个局域网 OCR 引擎。Vis Aware 会将所选图像发送到开源 iOS 应用 [OCR Server](https://github.com/riddleling/iOS-OCR-Server)，由该应用使用 Apple Vision 识别文字并返回文字坐标。该引擎不需要云端 OCR 账户，但电脑和 iPhone 必须能够通过同一局域网相互访问。

当前版本的应用要求 iOS 18.4 或更高版本，支持的最早机型为 iPhone XS、iPhone XS Max、iPhone XR 和第二代 iPhone SE。

配置步骤：

1. 在 iPhone 上从 [App Store](https://apps.apple.com/us/app/ocr-server/id6749533041) 安装 OCR Server。
2. 将 iPhone 和电脑连接到同一局域网，然后打开 OCR Server。服务器会自动启动并显示连接地址。
3. 打开 `NVDA 菜单 > 选项 > Vis Aware 设置... > OCR`，启用并选择 **Apple Vision Server**，然后填写应用显示的地址，例如 `192.168.1.10:8000`。

与 OCR Server 的连接使用未经身份验证且未加密的 HTTP。请仅在可信局域网中使用此引擎；在公共或不可信网络上，上传的图像和返回的 OCR 结果可能被截获或篡改。

使用该引擎时，请保持 OCR Server 在前台运行并让 iPhone 屏幕常亮。如需长时间连续运行，可按照原项目说明开启 iOS 引导式访问。应用使用方法和服务器 API 详见原项目说明。

### 推荐的离线方案：通过 Ollama 部署本地模型

如需离线、自托管方案，推荐借助 [Ollama](https://ollama.org/) 中部署具备视觉能力的模型。模型下载完成且 API URL 指向本地服务后，Vis Aware 会将图像发送到该本地服务。

支持填写完整 API URL，也可以填写主机和端口，例如 `localhost:11434`。默认 API 根地址为 `http://localhost:11434/api`。

使用**获取模型**加载模型名称，然后选择模型。如果未选择模型，将使用 Ollama 返回的第一个模型。

API 密钥是可选的。Ollama 引擎需要支持视觉能力的模型，例如 Gemma 4；仅当模型返回有效的结构化 OCR 数据时，Ollama 才会提供屏幕坐标。

### 其他引擎

* PaddleOCR 支持 AI Studio 托管任务 API、AI Studio 部署服务和自托管 PaddleOCR 服务；可在引擎设置中选择 PaddleOCR 或 PaddleOCR-VL 作为服务类型。
* Kimi 引擎使用 OpenAI 兼容协议。使用 Kimi 开放平台请填写在 [Kimi 开放平台](https://platform.kimi.com/console/api-keys) 创建的密钥；使用国际平台时，请填写在 [国际 Kimi 平台](https://platform.kimi.ai/console/api-keys) 创建的密钥。请勿混用端点和密钥。默认模型为 Kimi K3；可用模型和思考选项会随端点及模型系列而异。
* DeepSeek 引擎使用 OpenAI 兼容协议。请将 Base URL 设置为 `https://api.deepseek.com`，在 [DeepSeek API 控制台](https://platform.deepseek.com/api_keys) 创建密钥并填写到引擎设置中。默认视觉模型为 `deepseek-flash`，图像描述和 AI Agent 引擎均使用该模型。

## 数据和凭据

识别会将所选图像以及适用时的提示词发送给所选引擎配置的服务。AI Agent 每一步都会向所选服务发送全屏截图，其中可能包含其他窗口的内容。请查阅相应服务的数据政策，并避免发送敏感内容。

在支持的系统上，使用 NVDA 2026.3 或更高版本时，即使启用了黑屏或 NVDA 内置放大镜，手动和自动屏幕识别也可以捕获原始屏幕截图。

部分敏感登录会话使用 Windows DPAPI 保护；其他保存的 API 密钥会以明文形式存储在 NVDA 配置中，在创建或分享 NVDA 便携版之前请务必留意数据安全。
